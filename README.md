تم تطوير «مساعد رونق» ليبدأ كمساعد خدمة عملاء طبيعي قبل الترشيحات.

أمثلة:
- أهلا → «أهلاً بحضرتك في رونق للعطور...»
- السلام عليكم → رد السلام والترحيب.
- إزيك؟ → رد طبيعي ثم عرض المساعدة.
- ساعدني → يبدأ مساعدة تدريجية.
- شكراً → رد خدمة عملاء طبيعي.
- آه / تمام / ماشي → يكمل الحوار بدون ترشيح عشوائي.
- لا → ينهي بشكل لطيف.

الترشيحات لا تبدأ إلا عندما يكتب العميل اسم عطر أو مواصفات مفيدة مثل:
صيفي، شتوي، حريمي، رجالي، يونيسكس، فريش، زهري، خشبي، حلو... إلخ.

ويظل سياق الاختيار محفوظاً أثناء نفس المحادثة.

# Rawnaq Perfumes — Premium V4

تم إصلاح مشكلة المربعات الصغيرة من أصلها:
- استرجاع Font Awesome الصحيح بعد تغيير الخط العربي.
- حذف أي أيقونة إضافية بجوار «اطلب الآن».
- أيقونة البحث أصبحت عدسة بحث حقيقية بدون مربع.
- حذف الزرين بجوار «حرّك القائمة».
- حذف أي زخرفة/أيقونة صغيرة بجوار عناوين قوائم الأسعار.
- أيقونات أقسام المنتجات أصبحت دوائر ذهبية/رمادية مثل الشكل المرجعي مع نقاط للسحب.
- آراء عملائنا بمحاذاة يمين مع مسافة بسيطة من حافة الصفحة.
- أيقونات التواصل: واتساب / فيسبوك / إنستجرام / تيك توك داخل دوائر ذهبية Outlined وأسفل قليلاً.
- كل سطر في «تواصل معنا» له أيقونة مستقلة، والنص Off-white.

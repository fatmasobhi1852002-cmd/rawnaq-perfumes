# Rawnaq Perfumes — Premium V7 Chat

مساعد رونق أصبح محادثة تفاعلية:
- يفهم اسم العطر أو جزء منه.
- يفهم صيفي/شتوي/حريمي/رجالي/يونيسكس/فريش/حلو وغيرها.
- يحتفظ بالسياق: لو قلت «صيفي» ثم «حريمي» يجمع الشرطين.
- «ساعدني» يرد بشكل طبيعي.
- الكلام غير المرتبط بالعطور لا ينتج عنه اقتراح عشوائي.
- «اقتراح تاني» يستخدم نفس مواصفات المحادثة.
- زر محادثة جديدة يمسح السياق.

الكود المرسل الخاص بـ SentenceTransformers + ChromaDB + Gemini مناسب لباك إند Python منفصل.
هذه النسخة تطبق نفس منطق المحادثة داخل نسخة Vercel one-link بدون باك إند ثقيل.

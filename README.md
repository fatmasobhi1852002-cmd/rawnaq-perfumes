# Rawnaq Perfumes — Premium V2

تم تعديل:
- خط عربي أكثر رسمية وأناقة.
- إدخال الأوف وايت في الواجهة.
- تثبيت ظهور شريط التنقل على اللابتوب وإتاحته بالسكرول.
- إضافة أسهم ونقاط لسكرول أقسام المنتجات.
- إضافة أيقونات مخمريات ولوشن.
- قوائم الأسعار أصبحت جنب بعض بسكرول أفقي + نقاط وأسهم + شرح الفرق.
- تحديث الريفيوهات وتصميمها في مستطيلات صغيرة بحد أوف وايت.
- منع الصفحة الخلفية من السكرول أثناء فتح مساعد رونق.
- اقتراح أسماء العطور أثناء الكتابة.
- منع مساعد رونق من إعطاء عطر عشوائي عند عدم وجود الاسم.
- تصغير وتنظيم سكشن التواصل للموبايل.

ملاحظة: اللوجو ما زال JPEG الحالي. للحصول على PNG متفرغ بجودة جيدة، يلزم رفع صورة اللوجو الأصلية.
